RACK POWER & THERMAL
Nearly 100% of electrical power becomes heat. At 12.7 kW this rack rejects ≈ 43,300 BTU/hr — roughly 3.6 tons of cooling. Plan CRAH / row cooling + hot-aisle containment accordingly.
HOW TO USE THE LAB
  1. Orbit / zoom / pan freely. Start in Rack View — full 42U.
  2. Click any server → see U position, purpose, power.
  3. Inspect Slice pulls it on rails and opens it on the bench.
  4. In Slice View click CPUs, DIMMs, GPUs, fans, PSUs, drives for specs.
  5. Toggle Airflow / Power / Data to learn why layout is ordered front→rear.
  6. Try Cutaway, Explode, Open Cover and inject failures to see redundancy.
  7. Return to Rack slides it home. Reset clears everything.
