Engineering assumptions

The 19-inch rack uses 44.45 mm units. System power is an approximate AC design load; all telemetry is a slow-changing local simulation. Each A/B feed is independently sized for the complete 13.32 kW design load (415 V, 32 A, three-phase, 80% design loading). GPU power supplies are four high-line 4 kW modules in a 2+2 arrangement.

Storage nodes use two 12-drive, dual-parity groups. Capacity labels distinguish raw from usable storage. PSU and network failures preserve operation using the remaining feed or link. Multiple injected faults can exhaust that protection.

Visualization, not circuit analysis

Power and data lines show conceptual dependencies, not exact PCB traces. Air streams illustrate intake, fin channels, and exhaust, not a CFD solution. The open U13-U16 service space must be blanked before production operation. The optional enclosure demonstrates removable panels and perforated doors.

All hardware is generated locally in this document. Only Three.js, its official helpers, and the required utility CSS runtime are loaded from a CDN. No hardware models, photographs, or texture files are used.
