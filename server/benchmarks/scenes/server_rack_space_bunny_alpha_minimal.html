ARCHITECTURAL CAPABILITY COMPARISON

Relative design emphasis only — not measured benchmarks. Bars communicate architectural capability and complexity.
General-purpose systems optimize balanced cost and serviceability. Virtualization and database nodes allocate space to CPU channels, ECC memory and I/O. GPU systems trade depth for accelerator density, power and cooling. Storage systems give most chassis volume to serviceable drive carriers and a visible backplane plane.
